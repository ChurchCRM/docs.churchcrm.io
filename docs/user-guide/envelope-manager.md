# Envelope Manager

**Finance → Admin → Envelope Manager** assigns a donation envelope number to each family. The page is `ManageEnvelopes.php`. Turn envelopes on under **Admin → System Settings → Financial Settings**. The switch reads **Enable the use of numbered donation envelopes for tracking contributions**. When it is on, envelope numbers show on finance lists.

**Family Select** limits the list to families with at least one person in a classification, or **All**. **Sort by** uses **Last Name** or **Envelope Number**.

Each row is a family name and an envelope number you can type over. Duplicate numbers are highlighted.

- **Assign starting at #** — numbers every family in the current list, starting at the number in the box.
- **Zero** — sets every envelope in the current list to 0.
- **Update Family Records** — opens **Update Envelopes**. **Confirm** writes the numbers on this page over the family records. **Cancel** closes the dialog without saving.
- The print button beside **Update Family Records** opens the envelope report.

Nothing is stored until you confirm **Update Family Records**.
