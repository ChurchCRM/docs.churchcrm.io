# User Documentation

This section covers day-to-day usage of ChurchCRM for end users. For system administration tasks, see the [Administration](/administration) section.

---

## Quick Start Guide

New to ChurchCRM? Here's how to get started:

1. **Add your first family** → [Families](/user-guide/families)
2. **Add family members** → [Persons](/user-guide/persons)
3. **Organize into groups** → [Groups](/user-guide/groups)
4. **Set up classifications** → [Classifications](/user-guide/classifications)
5. **Start tracking donations** → [Finances](/user-guide/finances)

> **Tip:** Follow [Your First Week with ChurchCRM](/getting-started/first-week) for a day-by-day setup guide. Use the [Search](/user-guide/search) feature (press `?`) to quickly find any person, family, or group.

---

## Make More Room on Wide Pages

On a desktop screen, use the **Collapse sidebar** button (the menu icon in the top header) to fold the left menu into a narrow rail of icons. Lists, the map, and reports then use the extra width. The rail opens to the full menu while you point at it or move to it with the keyboard. Click **Expand sidebar** to keep the full menu open again.

ChurchCRM saves your choice with your user account, so the sidebar stays as you left it on every page, and on any device you sign in from, until you change it.

On tablets and phones the button is not shown. Open the menu with the hamburger button as usual.
