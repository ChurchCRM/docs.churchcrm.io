# Docker Development Environment

**This page has moved.** The Docker development environment guide now lives with the other developer pages: [Docker Development Environment](../developers/docker.md).

That page covers the complete Docker-based development environment for working on the ChurchCRM source code — prerequisites, the quick-start setup, the container services (webserver, database, mailserver), the npm scripts, and troubleshooting for container, permission, and database issues. Churches running ChurchCRM in production with Docker should use the [Docker installation guide](../installation/docker.md) instead.
