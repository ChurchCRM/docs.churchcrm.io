# Reporting Issues

**This page has moved.** Its content is now part of the [Bug Reporting & Diagnostics Guide](/administration/bug-reporting-and-diagnostics).

The guide covers the fastest ways to get help: the in-app **Support → Report an Issue** tool, which captures your environment automatically; when to use GitHub issues instead; what diagnostic information to gather before you report; and how to format and share logs so the team can act on them quickly.
