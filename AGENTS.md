# Documentation agent entry point

Read [.agents/DOCS_GUIDE.md](.agents/DOCS_GUIDE.md) first; it owns release branches,
tracking conventions, publishing and media rules. Load only the task-specific card
under `.agents/skills/`, and use its task-first docs voice with exact released UI labels.

Read [the shared AI operating model](https://github.com/ChurchCRM/CRM/blob/master/docs/contributing/ai-operating-model.md) for ownership and approval boundaries.
Claude Code owns complex engineering/docs; Codex or Copilot implements scoped changes.
The role guide is proposed in a companion CRM PR; it does not override DOCS_GUIDE.
Do not add a second capture engine or commit new screenshot/video files here.
